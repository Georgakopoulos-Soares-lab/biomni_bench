# Candidate-agent reproducibility audit (2026-08-25)

This is a practical audit, not a paper-existence list. “One GH200” means a single 95.6 GiB device; estimates exclude large benchmark data and tool images. Repository snapshots and license claims must be rechecked and pinned before an execution is admitted.

## Recommendation and experiment gate

The recommended three-agent panel is **Biomni**, **CellVoyager**, and **BioMaster**: they span a broad biomedical tool agent, a single-cell notebook agent, and a multi-agent bioinformatics workflow system. This is a provisional panel, not an assertion all three are executable today. Only Biomni is admission-ready now. CellVoyager enters after a credential/scorer smoke; BioMaster enters after its published benchmark data and deterministic native scorer are confirmed. BioMedAgent and BRAD are backups, not substitutes for those gates.

## Proposed full matrix — do not launch

For each admitted agent-native benchmark, sample 50 predeclared public or already-consumed instances stratified by task family, run K=4, and report the v1 output plus per-family tables. Repeat the exact held-out panel before and after any later approved intervention. Pilot costs are necessarily ranges until smokes measure wall time: Biomni's observed historical rate is roughly 310 s per trajectory (about **17 GPU-hours** for 50×4 serial GPU trajectories); CellVoyager API-client work is GPU-light locally but paid-provider time is unknown; BioMaster is dominated by tool execution and model/provider choice. No full campaign is authorized by this document.

# Reports — where to start

This directory holds every preregistration, result, and audit produced
during the project (see [PROJECT_STATUS.md](../PROJECT_STATUS.md) for the
full chronological log). For a first read, these six cover the current
scientific state:

| Report | Why read it |
| --- | --- |
| [reliability_suite_v1.md](reliability_suite_v1.md) | The frozen, agent-agnostic evaluation spec every result below is measured with. |
| [auroc_definition_methods_note.md](auroc_definition_methods_note.md) | The harmonized cross-agent reliability comparison (Biomni vs. GenoMAS vs. AutoBA) and the metric-definition correction behind it. |
| [phase2_report.md](phase2_report.md) | The prospective test of an online reliability controller — both co-primary hypotheses failed against a fixed-K baseline. |
| [track_c_diversity_diagnostic.md](track_c_diversity_diagnostic.md) | Why a trajectory-diversity mechanism was ruled out as the controller's next step. |
| [biomni_trajectory_distillation_audit.md](biomni_trajectory_distillation_audit.md) | The audit of the training corpus behind the current distillation pilot: counts, taxonomy, token accounting. |
| [biomni_distillation_pilot_preregistration.md](biomni_distillation_pilot_preregistration.md) | The frozen design for the distillation experiment now in preparation. |

Everything else in this directory is primary evidence for those reports —
preregistrations, admission audits for candidate agents, forensics,
per-phase results — kept for provenance rather than as a second reading
path.
